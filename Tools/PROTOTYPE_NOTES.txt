Coastal Loop / KiyiDongusu — V1.0.9.0 preview
Windows x64. Keep KiyiDongusu.exe with all accompanying files.
Click / Space: collect from the pile; help processing while it is empty.
Start by clicking the six paper pieces. The first paper pile appears afterward.
Buy a matching material container with credits, then drag loose litter into it for +0.50 after recycling.
Container prices: paper15, cardboard20, PET30, HDPE35, aluminium40, glass45 credits. Containers are optional.
New litter materials and piles appear as their free processing lines unlock.
Collected litter is raw stock. Only finished processing pays credits.
Tab / Enter: buttons. Arrow keys: selected volume slider. Esc: settings / pause.
Settings: master, music, effects, ocean, mute, English/Turkish, resolution, fullscreen and reduced motion.
Six materials share four facilities; each material processes independently in parallel.
Buy a collection crew to continue collecting automatically.
Autosave runs every ten seconds and on important changes/normal exit. No offline production.
If a save fails, the game retries; an unsuccessful final save keeps the game open with a warning.
New game requires confirmation and preserves previous files locally.
Normal save: LocalLow/KiyiDongusuLocal/KiyiDongusu. Never run two normal copies at once.
No player save or test currency is distributed in this folder.
This preview is not final delivery. Normal human playtime and listening/balance checks remain.
